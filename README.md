# sweetshop_automation

Playwright automation and QA documentation for the Sweet Shop demo application.

## Scripts

- `npm test` runs the Playwright end-to-end suite.
- `npm run test:headed` runs the suite in headed mode.
- `npm run test:ui` opens the Playwright UI runner.
- `npm run report` generates the execution report.

## Test Target

By default, tests run against `https://sweetshop.netlify.app`. Set `BASE_URL` to run the suite against another environment.
